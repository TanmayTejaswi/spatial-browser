# Course Materials and User Study Alignment Review

**Reviewed:** 2026-11-23  
**Scope:** All 16 PDFs in [`Materials for user study/`](../Materials%20for%20user%20study/), the extension's study controller and controlled topic packs, and the current user-study plan, runbook, session sheet, and data dictionary.

## Review outcome

The project fits the HCI course focus: it supports a real retrieval goal, uses an interaction model that represents browsing relationships, and evaluates usability with controlled tasks. The study is a two-condition within-subject comparison, which matches the course's WSD material. The project should be presented as a **feasibility pilot**; a 10–15-person convenience sample can expose procedure and usability problems and estimate outcomes, but it cannot establish a general causal claim that the extension is superior or reduces cognitive load for everyone.

Review found concrete alignment issues, now corrected in the working copy:

1. Some study-page links let a participant reach or reopen the retrieval target at the wrong point in the browsing schedule. The early shortcuts and late target backlinks were removed from the solar-efficiency, solar-economics, winter-history, and Olympics-economics pages. Task 3 now uses the target's related report and asks about the page just read before the target; it does not require reopening the target.
2. NASA-TLX sliders showed `50` before a participant answered, and the round-start control remained prominent during rating entry. The interface now marks each scale **Not rated**, hides the unselected thumb, records a midpoint only after deliberate selection, keeps saving disabled until all six scales are selected, and calculates the raw mean only then. When ratings are pending, the panel hides the next-round start control and opens at the rating section.
3. The plan distinguished the privacy-limited study export from ordinary history storage but did not give a complete participant disclosure. The approved-consent checklist and runbook now explicitly disclose that the normal map stores page titles and addresses while enabled, separately from the allowlisted study export.
4. The follow-up question is now neutral and standardized, and qualitative comments are described as descriptive unless an explicit coding method is used.
5. The analysis notes now match the course's paired-design teaching: if an inferential comparison is approved for a numeric two-condition outcome, use a preselected paired method; there is no post-hoc comparison for just two conditions. The 10–15-person pilot is not used to claim statistical proof.
6. The data dictionary now describes timeout as reaching the 120-second limit, consistent with the controller's cap.

## Alignment decisions and limits

- Keep the user-study question focused on retrieval effectiveness, successful retrieval time, and self-reported workload. Do not claim that recorded page opens are literal misclicks or that the extension can infer intention.
- Keep the local topic packs matched in page count, target depth, link opportunities, and cue difficulty. The researcher dry run still needs to confirm that the 15-minute schedule sustains the task without idle waiting.
- The four sequences balance tool order and pack assignment, but a small pilot will not remove every carryover or topic effect. Report the sequence counts and protocol deviations.
- The pilot is a feasibility and estimation exercise. Use it to improve materials and plan a later, adequately powered study; do not present its p-value alone as proof of superiority.
- Obtain supervisor and institutional approval for recruitment, consent, storage, retention, and analysis before any participant session. This review did not recruit participants or collect human-subject data.
